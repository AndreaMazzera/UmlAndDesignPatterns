# UML and Design Patterns

<img src="assets/icons/icon.svg" align="right" width="200">

This repository serves as a structured knowledge base covering the fundamentals, diagram types, and design patterns of the **Unified Modeling Language (UML)**. 

The notes are organized into three main sections, alongside a dedicated references file:

* **`uml_introduction.md`**: Covers core concepts, historical context, evolution to UML 2.0, RAD methodology, and software tools.
* **`uml_diagrams.md`**: Provides a detailed breakdown of structural and behavioral UML diagrams with practical examples.
* **`uml_design_patterns.md`**: Focuses on Creational, Structural, and Behavioral Object-Oriented Design Patterns represented through UML.
* **`references.md`**: Lists the sources, documentation, and external resources used throughout these notes.

While all Markdown files (`.md`) are fully readable directly here on GitHub, they contain custom layout elements (such as floating images, side-by-side figures, and custom typography) that GitHub's default Markdown renderer strips out.

To view the notes with full custom styling:
1. Clone or download this repository.
2. Open the `main.html` file in any web browser (Chrome, Firefox, Edge, Safari).

This will load the interactive web version, preserving the intended visual layout and responsive design.
